# Litma reel: nine writing types (Remotion)

Nine real first pages (from `../capture`, `npm run pages`) land on the desk one per beat, then the end card.
`src/Reel.tsx` holds the timing (`PICKER`, `BEAT`, `TYPES`, `LANDINGS`), `src/brand.ts` the colours from
`apps/web/src/styles/theme.css`, `src/Sticker.tsx` the Instagram-style caption box.

```bash
npm install
npm run dev      # Remotion Studio
npm run render   # out/litma-reel-2-writing-types.mp4 (1080 x 1920, 30 fps)
```

See `docs/marketing/reels.md` for the whole workflow.
