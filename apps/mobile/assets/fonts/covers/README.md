# Book-cover title fonts (phone app)

The same title fonts as the web's `COVER_FONTS`, as TTF (Flutter can't load WOFF2). All under the
SIL Open Font License 1.1 (see each `*-LICENSE.txt`).

- Karumbi, Dyuthi, Uroob, Meera, Rachana: Swathanthra Malayalam Computing (SMC). Converted unchanged
  from `apps/web/public/fonts/smc/*.woff2` with fontTools.
- Chilanka (SMC) and Baloo Chettan 2 (Ek Type): from github.com/google/fonts. Baloo Chettan 2 is a
  variable font; the two static weights here (400, 800) were cut from it with fontTools' instancer.
