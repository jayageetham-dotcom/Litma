# Malayalam fonts for book covers

Bundled so cover titles look the same on the website, the desktop app and in PDFs. All are by
Swathanthra Malayalam Computing (SMC, https://smc.org.in) and contributors, under the SIL Open Font
License 1.1 (see each `*-LICENSE.txt`). Converted from the TTF files in the SMC GitHub repositories
(github.com/smc/<name>/ttf) to WOFF2 without changes to the glyphs.

| File | Style |
|---|---|
| Karumbi.woff2 | handwritten calligraphy |
| Dyuthi.woff2 | decorative calligraphy |
| Uroob.woff2 | bold display |
| Meera.woff2 | sans |
| Rachana-Regular.woff2, Rachana-Bold.woff2 | traditional serif |

Nupuram Calligraphy would be a good addition later; its sources are MetaPost and need a TeX build.
