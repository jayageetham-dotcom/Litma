Owner's ask (26 Nov 16:10): why are words with എന്നാണ് / എന്നുള്ള still flagged; check with the MCP whether capitals in Manglish work the same online in the phone app; fix the tall right-click menu covering the clicked line ("use auto align if needed without compromising performance"). Lead: Claude session (claude.ai/code) · Started: 2026-11-26

## Decisions
- 2026-11-26 Exact spelling with capitals only for meaningful capitals inside a word (`exactReading`); name-style capitals (Kerala), words in capitals (TV) and meaningless capitals (iPhone) keep Google's reading. This also corrects PR #19, where any capital led with the letter reading (Kerala → Kഎരല).

## Build (web-dev + flutter-dev, done by the lead)
- Why flagged: `quoted()` only matched എന്ന്/എന്നു/എന്ന/എന്നും/എന്നോ; mlmorph can't chain longer endings after a long negative (കാണാനില്ലെന്നാണ്), though it knows them after ഇല്ലെന്ന. Now any tail mlmorph accepts after ഇല്ലെന്ന is allowed, still only after a negative. `quoted-check.ts` covers the long endings (prose 21 of 345 flagged, was 22; false passes 73 of 1,628, all with a base mlmorph itself accepts; MUST_OK/MUST_FLAG extended).
- MCP check (Litma MCP `transliterate`, Google behind it): `pani paNi kalam kaLam vattam vaTTam kodi koDi` → `പണി പണി കാലം കാലം വട്ടം വട്ടം കോടി കോടി`: Google ignores case. Phone `Transliterator.candidates` put Google first, so kaLam gave കാലം online. Fixed in `_shared/google.ts` (litma-transliterate and MCP), web `ManglishPopup`, phone `config.dart`, offline rankers (TS + Dart) via `exactReading`.
- Menu: placed by the clicked line's rect (`coordsAtPos`): below if it fits, else above, else the roomier side with `maxHeight` and its own scroll; one layout read per opening. Playwright at 1440×900, 1024×600, 1024×420, five heights each: never overlaps the line, always inside the window.
- Checks: typecheck, build, i18n:check, sync:shared, mobile:assets (vectors regenerated). Dart not compiled here: Mobile app checks.

**Failures** (→ web-dev / flutter-dev; none is a regression from main, but 1 and 2 are holes in what this branch claims)
1. **Garbage and slipped endings pass after any negative** (`quoted()`, mlmorph.ts). mlmorph reads ഇല്ലെന്ന… as ഇ<dem>+അല്ല്<n>+എന്നു്, then compounds or vowel letters, so `accepts("ഇല്ലെന്ന" + tail)` is loose. Accepted now (were flagged before this branch): കാണാനില്ലെന്നയിരുന്നു (ാ missing), വരില്ലെന്നാനോ, വരില്ലെന്നാണൊ, doubled quotative വരില്ലെന്നെന്ന് / വരില്ലെന്നെന്നാണ് (a common double-typing slip), and junk കാണാനില്ലെന്നോര, -ന്നട, -ന്നര, -ന്നറി, -ന്നിട, -ന്നനട, -ന്നതട, -ന്നുാക, -ന്നേൂല, -ന്നോേ (last three are broken Unicode: two vowel signs). Rates: random 1–4 letter tails 3.95% accepted (778 of 19,701); slipped long endings 41 of 701 (5.8%); quoted-check §6 29 of 29. Option I measured: accept a tail only if `ഇല്ലെന്ന`+tail has a reading without `compound`, `<quantifier>`, `<indeclinable>`, `<interrogative>` and no two vowel signs in a row: blocks all the junk and the misspelt endings, keeps ്/ു/ും/ോ/ാണ്/ുള്ള/ായിരുന്നു/ാണോ/ല്ലേ/ുമാണ്/ാണെന്ന്/ായി/ത്/താണ്/തിനാൽ/ൊക്കെ/ുതന്നെ/ുപോലും/ുമല്ല/ുമുള്ള/ാൽ/ിട്ടും, but loses ാകും ാവും ോർത്ത് റിയാം മട്ടിൽ ുവെച്ചു (only compounds), which MUST_OK now requires; so it needs a small allow-list for those, and doubled എന്ന still passes. Your call; quoted-check §6 (`TAIL_SLIP_MAX = 29`) fails if it gets worse; lower it when fixed.
2. **Capitals still give Latin junk outside the exact-first rule** (manglish.ts / manglish-rank.ts / google.ts / config.dart / manglish_rank.dart). Repro on the web: local-mode dev server (no `/dict`), Manglish mode, type `Kerala ` → **Kഎരല** in the text (screenshot manglish-after-menu.png). Same whenever the word list hasn't loaded yet or fails: `offlineCandidates` falls back to `manglishCandidates(word)` and `commit` to `manglishWord(st.word)` with the raw capitals. With the list loaded the ranker still lists junk: vectors now show Kerala → [കേരള … Kഎരല, Kഎറല, Kഎരള, Kഏരല], TV → [ട്V] only, YouTube → [യൗടുബെ, Yഔടുബെ…], iPhone → […ഇPഹൊനെ], Ammu → ആമ്മു but no അമ്മു. Server: `googleCandidates` appends `local = manglishWord(word)`, so online lists get Kഎരല / ട്V / ഇPഹൊനെ last, and with Google down MCP `transliterate` gives Kഎരല for Kerala and ആമ്മു for Ammu. Fix idea: one case-folding helper (same rules as `exactReading`: name case and all caps → lower, meaningless capitals → lower) applied before every `manglishWord`/`manglishCandidates` fallback, TS and Dart.
3. **Brand-style capitals lead with a letter reading** (`exactReading`). Any word with a meaningful capital that isn't name case: YouTube → യൗടുബെ, WhatsApp → വ്ഹട്സാപ്പ്, TikTok → ടിക്ടൊക്, GitHub → ഗിടഃഉബ്, iOS → ഇഓശ്, macOS → മചോശ്, LinkedIn → ളിങ്കെടീൻ, McDonald → ംച്ഡൊനല്ദ്, ChatGPT → ചട്ഗ്പ്ട്, OpenAI → ഓപെനാഈ, PhD → ഫ്ഡ്. Space takes the first, so typing `YouTube ` in Manglish writes യൗടുബെ instead of Google's യൂട്യൂബ്. Also NaLLa → ണള്ള before നല്ല (consistent with the scheme; just noting). Suggest: CamelCase (a capital right after a lower-case consonant letter that starts a new English-looking part, or more than one capital that each start a part) keeps Google first, or exact goes second when Google has an answer.
